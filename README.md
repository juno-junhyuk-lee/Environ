# Environ

Environ is a web application that aims to raise awareness about sustainable development and climate-conscious cities.

Users build their own civilization from three elements:

- **Human settlements**
- **Forests**
- **Fresh water bodies**

As the simulation progresses, users see how their choices affect the environment, themselves, and future generations.

## Why Environ?

The connection between human activity and its environmental consequences is often hard to grasp. Environ addresses this by letting users experience those effects directly through an interactive simulation, rather than reading about them in the abstract.
